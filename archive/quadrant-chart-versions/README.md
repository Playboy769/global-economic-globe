# 象限圖工具 — 未採用的設計版本

象限圖工具原本做了三個設計版本並存，由一個 `index.html` 選擇頁分流。2026-08-09 定案
**採用 v1 極簡風**，並把它升為 `projects/quadrant-chart-demo/index.html`（選擇頁一併移除，
否則只剩一版時那頁會留下兩個 404 連結）。

這裡存的是未採用的另外兩版，僅供參考，**不再維護**：

| 檔案 | 版本 | 特徵 |
|---|---|---|
| `v2-dashboard.html` | v2 · 儀表板風 | 卡片式版面，四象限各自可配底色，清單計數與分區編號引導 |
| `v3-techviz.html` | v3 · 科技資料視覺化風 | 等寬字體、細格線與座標刻度、即時游標座標讀出 |

## 為什麼留 v1

象限圖的用途是產生要貼進 earnings 分析報告的圖，而報告有「一律純白底＋高對比深色字，
顏色只准用在徽章、邊框、色條、小面積強調元素」的視覺鐵則（見根目錄 `CLAUDE.md`）。
v1 本來就是這個路線；v2 的象限底色與 v3 的格線質感都會在報告裡顯得突兀，而且和
`projects/chart-tools/` 那套工具的外觀不一致。

## 三版共通、v1 也保有的功能

可自訂 X/Y 軸名稱、4 個象限名稱、軸範圍（±N）、黑色 XY 軸＋白底、點擊畫布或表單新增
資料點、資料點可拖曳／改色／改名／刪除、匯出 PNG、複製可嵌入的 SVG 代碼。

版面設計參考了 BCG 成長占有率矩陣、Gartner Magic Quadrant、風險機率-衝擊矩陣等常見
象限圖的配置邏輯。

> 若要復原某一版：把檔案複製回 `projects/quadrant-chart-demo/`。注意這兩份是
> 2026-08-09 當下的樣子，之後 v1 的任何修正都沒有同步過來。
