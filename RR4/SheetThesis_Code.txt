Option Explicit

' ============================================================================
'  Worksheet code-behind for the "Thesis Library" sheet (RR4 workbook).
'  NOT a .bas module -- it lives in the sheet's own code module and is
'  written there by modThesis.EnsureThesisSheetCode when TH! builds the page.
' ============================================================================

' Thesis Library: double-click a row to read it in the panel (see modThesis.bas)
Private Sub Worksheet_BeforeDoubleClick(ByVal Target As Range, Cancel As Boolean)
    Call ThesisDoubleClick(Me, Target, Cancel)
End Sub

Private Sub Worksheet_Change(ByVal Target As Range)
    Call ThesisChange(Me, Target)
End Sub
