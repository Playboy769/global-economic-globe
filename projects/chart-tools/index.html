chart-tools

報告用圖表產生器

每個工具都在左側編輯資料、右側即時預覽，然後複製一段自包含的嵌入代碼貼進 earnings 分析報告的 .card 裡。輸出一律純白底、深色字，對齊報告的視覺鐵則。

本目錄的工具

折線圖

多系列、支援左右雙軸（金額走左軸、比率走右軸自動改虛線）。缺值真的斷線而不是補 0。

損益表 tab 的逐季／逐年趨勢、10 季走勢圖

甘特圖／時程區間

工期橫條、里程碑菱形、分組標題、跨列垂直參考線。日期可寫 2026-Q3 或 2026-08-09。

產能開出、客戶認證、長約履約期、專利到期

圓餅／甜甜圈

中空比例可調、圖例同時顯示數值與百分比。負值會被濾掉而不是取絕對值。

營收結構、成本結構、客戶集中度

瀑布圖

起點／增減項／小計／結束四種列型，累計自動算。小計與結束不吃自填值，避免跟累計對不上。

營業利益橋接、FCF 橋接、毛利率變動拆解

分層關係圖／產業鏈圖

固定分層＋帶標籤關係線，資料用 JSON 貼上而非表單。自動路由：跨層連結一律繞到畫布外側走道，保證不會壓到節點。

供應鏈上下游、產業鏈情狀、組織架構、因果鏈

長條圖

並排／堆疊／百分比堆疊 × 直向／橫向，六種組合。正值往上、負值往下堆；百分比模式遇到負值會在圖上明講略過幾筆。

BU 營收 QoQ、量價拆分、成本結構對比

散點／氣泡圖

可用中位數／平均數自動分四象限，另有最小平方趨勢線。氣泡面積正比於數值，不是半徑。

估值觀察 tab 的同業比較（P/E vs 成長率）

熱力圖／矩陣

可直接從 Excel 複製整塊貼上（千分位、%、破折號都吃）。深色格自動改白字，無資料畫斜線而不是留白造成混淆。

部門×季度矩陣、風險矩陣、供應商集中度

同系列的其他工具（各自獨立的資料夾與 port）

Sankey 流向圖

上下游供應鏈、營收流向、股權結構。用 D3 ＋ d3-sankey，嵌入代碼會自動注入 CDN—— 這是唯一依賴外部 CDN 的一個，離線時圖會空白。

projects/sankey-diagram-demo/　本地 port 8137

象限圖（2×2 散點）

兩軸定位＋資料點散布，可拖曳調整位置。輸出純 inline SVG。與本頁的散點圖不同： 這個是 ±N 對稱軸＋四個具名象限（BCG／Magic Quadrant 那種），不畫實際數值尺度。

projects/quadrant-chart-demo/　本地 port 8160

這兩個工具各有自己的 dev server 設定，不在本頁的 :8158 底下——本頁的伺服器根目錄就是 chart-tools/，跳不出去，所以刻意不做成連結而不是留一個會 404 的按鈕。

共通功能：貼上表格、跨圖配色一致、列印檢查

貼上表格：七個工具都能直接從 Excel／Google Sheets／10-Q 表格整塊貼上， 不必一格一格重打。解析器認得千分位、%、貨幣符號，以及財報慣用的 (1,234) 括號負數——最後這項若沒處理，整份損益表的費用項會全部變成正的。 — 與空白視為缺值，折線圖會斷線而不是補 0。

跨圖配色一致：同名系列在所有工具裡共用同一個顏色。一篇報告有六張以上的圖， 「資料中心」在折線圖是藍、在長條圖變紅，是因為每個工具各自從調色盤第 0 個排起—— 現在有一份共用登錄表擋掉這件事。換一篇報告時按「清除配色記憶」重新開始。

列印與色覺檢查：預設調色盤是為螢幕挑的，色相分得開但灰階亮度擠在一起 （#dc2626 與 #2563eb 實測只差 4，黑白列印下幾乎同一色）。 配色面板會即時檢查目前這組顏色在灰階與三種色覺缺陷模擬下是否兩兩可辨， 按「套用列印安全配色」可換成亮度刻意拉開的版本（前 6 色零問題）。

兩種嵌入輸出的差別

靜態 SVG：一段純 SVG，零 script、零外部連線。離線、列印、PDF 匯出都正常， 也不會被報告本身的 CSS 影響（所有樣式都寫在 SVG 元素的 presentation attribute 上）。

互動版：同一張 SVG 再加一小段 vanilla script，只負責 hover 提示與淡化效果， 一樣不連任何外部網站。因為圖形是實體 SVG、不是 JS 當場算出來的， 貼在 display:none 的隱藏分頁裡也不會出現畫不出來的狀況—— 最壞情況只是 script 沒跑，圖還在。

兩者都不需要改報告的 <head>。同一篇報告貼多張互動圖也不會互相干擾， 每段嵌入代碼都有自己的隨機 id。
