Ctrl/Cmd+Enter 在文字框內也能直接套用
{ title, caption, stages: [string, ...] // 由上而下的層級名稱 branches: { key: {label, color, dashed?} } // 關係線的分色定義 nodes: [{ id, stage(層索引,從0起算), title, sub?, note?, branch?, emphasis?, span? }] edges: [{ from, to, label?, branch?, side? }] // side: 'left'|'right' // ↑ 只影響「跨層」或「同層」連結繞去哪一側， // 相鄰層(stage 剛好+1)一律走中間的階梯狀走線 }
節點在同一層裡的左右順序＝JSON nodes 陣列裡的排列順序，工具不做自動排序最佳化； 要調整順序，直接調整陣列裡的先後即可。span:true 讓節點撐滿整層寬度，適合放「匯聚點／終端」。
