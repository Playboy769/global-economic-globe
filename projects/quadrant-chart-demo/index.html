象限圖工具 — 三個設計版本

黑色 XY 軸、白底、可自訂象限與軸名稱皆已具備。點卡片開啟該版本試用，確定要用哪個再回來告訴我。

MINIMAL

v1 · 極簡風

大量留白、細線條、低彩度，象限名稱以灰階小字呈現，適合放進報告或簡報。

  • 單色主視覺，介面乾淨
  • 點擊新增 + 表單新增
  • 拖曳移動 / 顏色自訂
開啟試用
DASHBOARD

v2 · 儀表板風

卡片式版面、象限淺色底色可自訂，資訊層次分明，適合當作分析儀表板的一個模組。

  • 四象限各自可配色（含底色）
  • 清單計數 / 分區編號引導
  • 拖曳移動 / 顏色自訂
開啟試用
TECH / DATA-VIZ

v3 · 科技資料視覺化風

等寬字體、細格線與座標刻度、即時游標座標讀出，偏向分析工具 / 終端機質感。

  • 格線與刻度可切換顯示
  • 即時滑鼠座標讀出
  • 拖曳移動 / 顏色自訂
開啟試用
三版共通功能：可自訂 X/Y 軸名稱、4 個象限名稱、軸範圍（±N）、黑色 XY 軸＋白底、點擊畫布或表單新增資料點、 資料點可拖曳/改色/改名/刪除、匯出 PNG、複製可嵌入的 SVG 代碼。設計參考了 BCG 成長占有率矩陣、Gartner Magic Quadrant、風險機率-衝擊矩陣等常見象限圖範例的版面配置邏輯。
