## 一、最長選項法則：整體是雜訊，分科才有訊號

排除含「以上皆是／皆非」的題目後（那類選項又短、命中率又極端，會污染長度統計），剩 2,625 題，其中 1,577 題有唯一的最長選項。

| 長度排名 | 命中率 | 95% CI |
|---|---|---|
| **最長** | **27.7%**（437/1577） | 26%–30% |
| 第二長 | 21.5%（339/1577） | 20%–24% |
| 第三長 | 25.1%（396/1577） | 23%–27% |
| 最短 | 25.7%（405/1577） | 24%–28% |

整體只比 25% 高 2.7 個百分點，信賴區間下緣剛好擦過 25%——**單獨拿來用幾乎沒有價值**。但分科之後完全變了：

| 科目 | 最長選項 | 最短選項 |
|---|---|---|
| **法規** | **34.2%**（170/497） | **19.5%**（97/497） |
| 財務分析 | 26.9%（137/509） | 25.0%（127/509） |
| **投資學** | **22.8%**（130/571） | **31.7%**（181/571） |

⚑ 法規選最長（34.2%）、投資學選最短（31.7%），兩科的最佳策略**完全相反**。財務分析則兩邊都沒訊號。整體 27.7% 之所以看起來平淡，就是因為法規的正效應被投資學的負效應抵銷掉了。

**要長多少才算數？** 反直覺的是效果並非越長越好：

| 最長選項 ÷ 其他三項平均 | 命中率 |
|---|---|
| 1.0–1.2 倍 | 16.7%（14/84） |
| **1.2–1.5 倍** | **32.9%**（159/484） |
| 1.5–2.0 倍 | 26.1%（150/574） |
| ≥ 2.0 倍 | 26.2%（114/435） |

⚑ 甜蜜點在**比別人長 1.2–1.5 倍**。只長一點點（1.0–1.2 倍）反而是全表最差的 16.7%——那種情況本質上是四個選項差不多長，「最長」不帶資訊。長超過兩倍也沒有加分。不過這條曲線是非單調的，樣本切細後每格只剩幾百題，**不建議把它當精確規則，只當「差不多長就別用這招」的提醒**。

## 二、絕對詞 vs 緩和詞：這是個迷思

「含『一定、必須、絕對』的選項通常錯，含『可能、通常、不一定』的通常對」是流傳最廣的應試法則之一。在這份考題上**它不成立**。

| 選項類型 | 命中率 | 95% CI |
|---|---|---|
| 含絕對詞 | 23.1%（37/160） | 17%–30% |
| 含緩和詞 | 20.3%（25/123） | 14%–28% |
| 兩者都含 | 7.9%（6/76） | 4%–16% |
| 都不含 | 24.8%（2681/10803） | 24%–26% |
| （對照）全稱選項 | 43.7%（97/222） | 37%–50% |

⚑ 絕對詞（23.1%）與緩和詞（20.3%）的信賴區間都涵蓋 25%，**兩者都跟亂猜沒有差別**；而且緩和詞不但沒有比較高，數字上還略低於絕對詞——與流傳的說法方向相反。唯一有訊號的是「同時含兩類詞」的選項只有 7.9%（n=76），那通常是又臭又長、堆滿修飾語的干擾項。

分科看也救不回來，而且投資學再次反向：

| 科目 | 含絕對詞 | 含緩和詞 |
|---|---|---|
| 投資學 | 35.0%（21/60） | 15.0%（9/60） |
| 財務分析 | 11.4%（4/35） | 24.5%（12/49） |
| 法規 | 18.5%（12/65） | 28.6%（4/14） |

⚑ 三科的方向各不相同且樣本都很小（最小的一格只有 14 個），**沒有任何可用的規則**。這一項的結論就是：別用它，把注意力放回題目內容。

**詞表（供覆核）**
絕對詞：一定、必定、必然、絕對、絕不、永遠、完全、毫無、全部、所有、任何、只有、只能、唯一、無論、必須
緩和詞：可能、或許、通常、一般而言、不一定、視情況、視需要、無從得知、難以確定、不確定、原則上、多半、未必、不確知

「僅」與「不得」刻意**未**列入絕對詞——「僅甲、乙」是組合題的骨架、「不得超過…」是法條常態用語，列進去只會製造雜訊。詞表命中的實際字詞已全部倒出到 `scripts/out/_words_audit.txt` 供覆核。

## 四、罰則題：出現最嚴重的懲罰時，選它

這是你額外指定的一項。判定嚴重度沒辦法純靠程式——「3 年以下有期徒刑併科 3 萬元罰金」與「2 年以下有期徒刑併科 240 萬元罰金」哪個重，需要判斷（以刑度為主要判準）。所以我用機械方式撈候選，再**逐題人工覆核**。

**篩選過程**：機械撈出 19 題候選（17 題四選項帶罰則語言 + 2 題題幹問罰鍰而選項為純數字），逐題閱讀後**納入 11 題、排除 8 題**。排除理由如下，可覆核：

| 排除題 | 理由 |
|---|---|
| 109-4 Q5（財務分析） | 「處分損失」的「處分」是會計用語，關鍵字誤抓 |
| 109-4 Q18 | 比的是責任「種類」（刑事／民事／皆有／無）而非嚴重程度，且含全稱選項 |
| 112-1 Q19 | 反向題幹「下列何者為非」——「選最重」邏輯不適用 |
| 113-1 Q16、113-3 Q5 | 董事解任的敘述是非題，選項不是可排序的罰則 |
| 114-3 Q6 | 反向題幹「下列何者為錯誤」 |
| 114-3 Q22、115-1 Q10 | 問「得為哪些處分」而非比嚴重度，正解是全稱選項 |

**兩個結論，穩健度不同：**

1. **「選最重」命中 63.6%**（7/11）。相對亂猜 25%，二項檢定 **p = 0.0076**。去重後（113-1 Q23 與 112-1 Q10 是同一題）為 6/10 = 60%。
2. **正解 100% 落在最重或第二重**（11/11，第三重與最輕掛零）。相對「隨機應有一半落在後段」，**p = 0.00049**。

⚑ 第 2 點才是真正該記的。即使 n=11 很小，「11 題全部落在前半段」在隨機下的機率只有 0.05%。**實務規則：罰則題先把最輕的兩個劃掉，再從最重的兩個裡選——優先選最重那個。**

典型例：114-3 之前的「違約不履行交割之刑事處罰」重複考過多次，選項是 1 年以下／1~7 年／5 年以下／**3 年以上 10 年以下**，答案永遠是最重的那個。

## 五、實戰優先順序

1. **法規科：形態技巧全部可用。** 依效力排序——以上皆是（77.6%）> 罰則選最重（63.6%）> 數字題刪最小（69.1% 落在中間兩個）> 選最長（34.2%）。
2. **投資學科：形態技巧全部不要用。** 以上皆是（5.3%）、最長選項（22.8%）、中間值（46.2%）全部低於基準，選最短（31.7%）是唯一略有訊號的，但也弱。
3. **財務分析科：只有中間值法則勉強可用**（55.5%），其餘接近雜訊。
4. **絕對詞／緩和詞：三科都不要用。**
5. 這些全部是**亂猜時的最後手段**，期望值最高的一項（法規以上皆是）也有兩成多會錯。

## 方法與限制

1. **樣本限於 109 年起。** 105–108 年 2,700 題無答案卡，等於捨棄近半考古題。
2. **罰則題 n=11 是全文最小的樣本。** 「選最重 63.6%」的信賴區間寬達 35%–85%，方向可信、精確值不可信。「不落在後半段」則因為是 11/11 的極端結果，即使樣本小仍具統計意義。
3. **嚴重度排序含主觀判斷。** 刑度與罰金衝突時我以刑度為主；責任類型（懲罰性＞連帶＞區別＞單獨）的排序更是法理判斷而非資料。11 題的完整題面與我的排序都印在 `scripts/out/penalty_report.txt`，請自行覆核。
4. **長度以字元數計。** 中英數混排時 CJK 與 ASCII 等寬計算，會略微低估含中文的選項長度。
5. **重複題造成樣本不獨立。** 本文各項的樣本量遠大於上一份專題（1,577 / 604 題 vs 222 個），稀釋效果較小，故未逐項做去重版本；唯獨罰則題已附去重結果。
6. **法規會修法**，舊題正解可能已變動，本文只統計當時的答案卡。
